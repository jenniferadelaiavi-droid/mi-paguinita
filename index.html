🌐 ¿Qué es una página web?

Una página web es un documento digital que podemos visitar con un navegador. Puede tener textos, imágenes, videos, enlaces y muchas otras cosas.

💻 HTML

Organiza el contenido y la estructura de una página web.

🎨 CSS

Permite agregar colores, estilos, tamaños y diseños.

🚀 Alojamiento web

Hace posible que otras personas visiten una página por Internet.

✨ ¿Cómo publicar una página gratis?

  1. Crear un archivo llamado index.html.
  2. Abrir una cuenta en GitHub.
  3. Crear un repositorio para guardar la página.
  4. Subir el archivo HTML al repositorio.
  5. Activar GitHub Pages en la configuración.
  6. Compartir el enlace de la página publicada.
¿Sabías que...?

GitHub Pages permite publicar sitios web estáticos sin tener que comprar un servidor propio.
